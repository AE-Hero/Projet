# Projet fil rouge : Real Estate Analysis

Bienvenue sur le site du projet fil rouge de la formation AE Hero.

Vous allez construire, chapitre après chapitre, un projet dbt complet sur les
**Demandes de Valeurs Foncières (DVF)**, avec une chaîne de CI/CD proche de ce
que vous rencontrerez en entreprise.

## Ce que vous trouverez ici

| [Requêter la prod](requeter-prod.md) | Interroger la base de production (versions publiées) |

- **Stack :** dbt, SQL, DuckDB, GitHub Actions
- **Données :** DVF (sujet libre possible, à faire valider)
- **Entraide :** communauté AE Hero
